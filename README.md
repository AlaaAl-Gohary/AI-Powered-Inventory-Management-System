# AI-Powered Inventory Management System

### Short Description

A full-stack inventory management web application built with ASP.NET MVC and SQL Server, enhanced with Generative AI capabilities for intelligent inventory analysis and natural-language business insights.

### About the Project

A complete business-oriented inventory management system designed to manage products, categories, suppliers, purchases, sales, and stock operations through a centralized platform.

The system provides real-time inventory tracking, automated stock updates, low-stock alerts, transaction management, and an analytical dashboard. It also includes secure authentication and an integrated AI assistant that allows users to interact with inventory data using natural language.

### Key Features

* Product management with CRUD operations, search, filtering, and pagination
* Category and supplier management
* Real-time stock tracking and automatic stock updates
* Low-stock alerts
* Purchase management with automatic totals
* Sales management with stock validation and automatic stock deduction
* Sales receipts and transaction history
* Dashboard with KPIs, charts, recent activity, and best-selling products
* JWT Authentication
* Secure user access and protected functionality

### AI Inventory Assistant

An integrated AI assistant connected to the application's business data, allowing users to ask natural-language questions such as:

* Which products need restocking?
* What are the best-selling products?
* What are the total sales this month?
* How much stock is available for a specific product?

### Technologies

C#, ASP.NET MVC, Entity Framework Core, SQL Server, JWT Authentication, Generative AI, AI Agents, Workflow Automation, HTML, CSS, JavaScript
